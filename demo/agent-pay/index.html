Motion study · 2026
Motion notes

这页动画怎么做的

01

开场路径绘制

SVG 路径设置 pathLength="1"，用 stroke-dashoffset: 1 → 0 绘制，760ms，cubic-bezier(.35,0,.15,1)，每条路径错开 12ms。

02

滚动出场

元素初始 opacity:0、translate:0 24px、filter:blur(8px)，进入视口后过渡 720ms，缓动 cubic-bezier(.22,1,.36,1)。

03

气泡按压

点击导航时用 WAAPI 把胶囊下压 6px 再回弹，340ms，中间关键帧使用 cubic-bezier(.22,1,.36,1)。

04

Agent 眨眼

眼睛用 skew(-7.86deg) scaleY(.08) skew(7.86deg) 保持倾斜不变形，150ms 完成一次眨眼；虹膜随指针用 rAF 插值。

05

对话与授权

消息以 translate + scale + opacity 入场，授权卡使用轻微回弹；确认后粒子从按钮中心向外散开，形成成交反馈。

06

卡片倾斜

pointermove 映射到 rotateX / rotateY，再用 CSS 变量控制 spotlight 的径向渐变位置，离开时回正。
